# Ported: ffsubsync

Source: https://github.com/smacke/ffsubsync
Commit: de310ac6944b8260431a48ee741e7063cec49b0f
License: MIT (`LICENSE` beside this file)

Timing sync (`internal/subtitles/timing`) is a Go port of ffsubsync's speech signals, FFT offset search (`ffsubsync/aligners.py`), framerate ratio search, golden-section search (`ffsubsync/golden_section_search.py`) and split-penalty search (`ffsubsync/split_aligner.py`), copyright 2019 Stephen Macke and modified for SlipStream.
