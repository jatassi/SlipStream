# Writing

Every string a person reads follows [WRITING.md](../../WRITING.md): UI copy, API problems, OpenAPI docs, Health items, task outcomes, logs, CLI output, Go error strings and email. A review of a diff that adds or changes such a string reads WRITING.md first and reports each violation with the string, the rule number and a rewrite. GLOSSARY.md isn't a UI word list. A glossary term reaches a screen only through its `_In UI_` line (WRITING.md rules 20 to 27).
