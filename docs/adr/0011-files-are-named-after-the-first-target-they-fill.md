# Files are named after the first Target they fill

All of a Work's files share one folder, because Plex, Jellyfin and Emby group versions only when they sit together. So every file of one Item and Edition needs a name no other file there can take. A file **fills** a Target when it is the one file that Target holds for its Edition, and no two files fill the same Target. So the version label in each file name is the first Target in Profile order that the file fills, through a `{Target}` token, and names can't clash by construction. A non-Standard movie cut puts `{edition-<Cut>}` right after the dash, before the label, as `Heat (1995) - {edition-Director's Cut} 4K HDR.mkv`, whatever Media Servers are linked. Episodes carry the plain cut in the label, as `The Wire - S01E01 - Extended 1080p.mkv`. A file template with renaming on can't be saved without `{Target}` and an Edition token, nor unless its grouping anchor is followed by ` - ` with no Item or file token before that ` - `. A movie's anchor is the folder name, so its file template starts with exactly the folder template's parts. The check compares parsed parts, not text, so `{Movie CleanTitle}` under a `{Movie Title}` folder fails. An episode's anchor is its `SxxEyy` block, and a daily show named by air date anchors on `{Air Date}`, as `The Daily Show - 2026-11-09 - Guest Name 1080p.mkv`. At render time a movie's anchor is the name of the folder the file lands in, not the rendered folder template, so a found folder named `Heat 1995` gets `Heat 1995 - 4K HDR.mkv`, and a title whose trailing dot the folder drops, such as `Monsters, Inc.`, can't name its files apart from its folder. Decided in [Import pipeline under Editions and Targets](https://github.com/jatassi/SlipStream/issues/42#issuecomment-6104383476), Q2, Q3, Q5, Q9 and Q15, [Edition file names every Media Server groups](https://github.com/jatassi/SlipStream/issues/85), and [S24 (Naming and renaming)](https://github.com/jatassi/SlipStream/issues/149).

## Considered Options

- **List every Target the file fills, as `Heat (1995) - 1080p + 1080p small.mkv`.** Rejected. Names grow with every overlapping Target, and the file is renamed whenever any one of them moves.
- **Label from file facts, as Radarr's `{Quality Title}` and v1's slot naming do.** Rejected. Two files with the same facts, such as two 1080p WEB-DLs filling different Targets, get the same name and need a tiebreak. The version picker shows quality strings instead of the Targets the admin defined.
- **A separate library root per Target.** Rejected. Media Servers stop grouping the versions.
- **`{edition-<Cut>}` before the dash, as `Heat (1995) {edition-Director's Cut} - 4K HDR.mkv`.** Rejected. Jellyfin and Emby group a folder only when every file name is the folder name followed by ` - ` (or `_`, `.`, a `[…]` block), so one such file ungroups every version in the folder. Measured on Jellyfin 12.2 and Emby 4.10.
- **The plain cut in the label, as `Heat (1995) - Director's Cut 4K HDR.mkv`.** Rejected. Labels read cleanly on Jellyfin and Emby, but Plex loses the edition.
- **A folder per Edition.** Rejected. Jellyfin and Emby show one movie per Edition with clean labels, but Plex without Plex Pass merges the folders back into one item, and every move, rename and refresh gains a folder.
- **Render the plain cut when no Plex server is linked.** Rejected. Linking or unlinking Plex would rename every cut's files.

## Consequences

- A file is renamed when what it fills changes, so an import can rename files it did not bring. Its Sidecars rename with it, and each Media Server gets a refresh.
- Renaming a Target or reordering a Profile can rename thousands of files. Those renames wait for the admin to confirm them in the rename plan.
- With renaming off for a Content Type, nothing changes a file name of that type except a rename plan, and its plans move only folders. Imports keep the downloaded name in the Work's folder, an import whose name is taken there goes to review, and Target renames and upgrades rename nothing. Each file's label and ` (extra N)` counter are still recorded, so turning renaming on names every file by this rule through one rename plan.
- Jellyfin and Emby show the tag in the version label, as `{edition-Director's Cut} 4K HDR`. An admin who wants clean labels and no Plex edition uses `{Edition}` instead of `{Edition Tag}`.
- Plex offers every Sidecar on every version of one Plex item, by Plex's design. Under Plex Pass each Edition is its own item, and Sidecars stay on their own version. Measured in the Media Server conformance suite, https://github.com/jatassi/SlipStream/pull/83 (README, Edition layouts).
- A Kept file is named with the label of the first Target it meets plus ` (extra N)`, where N is a counter, so two Kept files never clash. Decided in the [coherence pass](https://github.com/jatassi/SlipStream/pull/112), Q18.
- A Library scan never renames a file. It records each found file's label and ` (extra N)` counter as this rule computes them and leaves the file at the path it was found at, so the label in a found file's name can differ from its recorded label. A later change to what the file fills renames it by this rule, and S24 (Naming and renaming)'s rename plan renames a whole found library to the templates. A Work's folder is the folder of its files, so later imports land beside the found files. Decided in [Library scan and file probe](https://github.com/jatassi/SlipStream/issues/147), decisions 3 and 19.
