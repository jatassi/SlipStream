# Offline boundaries

This is the list of every external boundary SlipStream crosses and the one fake that stands in for it in the Fake world ([ADR 0014](adr/0014-offline-mode-runs-the-release-binary-against-wire-level-fakes.md)). Each fake speaks the real wire protocol, sits behind the fault proxy, and plays the shared fault vocabulary. Each spec PR that adds a boundary appends a row here and names its fake.
