# UI redesign direction prototype

Scope: the v2 design language and its four shells (admin desk, admin phone, portal phone, portal desk), as three directions behind one switcher. Visitor mode: Operate. Audience and job: PRODUCT.md (Admin first; Members in a calmer register). Constraints from the chef: dark only; premium, clean, refined components; exquisite but restrained; feels like an interface on a film set ten years ahead. Build path: code-led (no image generation). The chef asked for three built directions to pick from at the draft PR, so the decision page was not served; the roll still assigned A.

Seed 05f3b169 (operate). Grounded list by resonance: 1 House lights (cinema auditorium, light from the screen), 2 smoked-glass hi-fi (Rams, Bang & Olufsen), 3 Criterion catalogue and spine system, 4 film edge code and leader, 5 wind-tunnel streamlines (the name's literal reading), 6 repertory cinema programme, 7 main-title sequences. Assigned: 5. Pick: 1. Challenger verdicts: transit diagram competitive (product clarity), built as C; boarding pass and gate board competitive (portal clarity), donated; monochrome product canon competitive (clarity), shown as a demoted alternate; split-flap declined; orienteering declined; streaming wall declined (the category's own page).

## Direction contract A · Slipstream (assigned)

THESIS: SlipStream is a wind tunnel that work flows through; the admin reads the system as flow, laminar when work moves and an eddy where it breaks. Refuses the stat-card dashboard and the poster wall as home.
OWN-WORLD: tunnel graphite (#08090B, #0D0F12, #13161A), smoke-white ink #E9EDF1, light-sheet #9ED8FF for flow and focus, rhodamine #FF6F7D reserved for separation, fluorescein #C6F36B only for arrival. Archivo across widths (extended light for the system sentence and big numerals), Martian Mono for releases and paths. Smoke-white filled primary buttons.
STORY: the admin glances, sees calm flow and one eddy, opens it, resolves it, leaves.
FIRST VIEWPORT: 72 px labelled icon rail; 56 px top bar with title, ⌘K command field and live throughput; the system sentence in extended light type; the Tunnel full width (rakes: Wanted, Searching, Downloading, Moving, Importing, Library); then Needs you beside Arrived tonight; Nodes as bodies with live load.
FORM: wind-tunnel flow visualisation, my list position 5, seed key 05f3b169. Signature move: the Tunnel, one filament per job, speed from its rate, a vortex where it fails. Raises: rows mutate in place (split-flap); dye budget of four uses per screen outside the Tunnel (monochrome canon); rhodamine reserved for separation (orienteering); arrivals and failures stay marked until seen (gate board).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

THESIS: the library is the light source; a dark auditorium whose only colour comes from the Works on screen, and focus dims the house. Refuses a brand-accent dashboard; the art is the palette.

Jost for display and UI; each Work's title set in its own poster face on its hero.
STORY: at night the admin sees what arrived glowing, what is still developing, and two aisle lights marking what needs them.

Art lights its surroundings; hover dims the house; a Work in progress is a monochrome poster developing into colour to its progress. Raises: focused tile lifts and reveals what it is while the rest recedes (streaming wall); portal requests as ticket stubs that tear when ready (gate board); amber budget of three per screen (monochrome canon).

## Direction contract C · Night Line (challenger, competitive)

THESIS: SlipStream is a network; Role Groups are lines, Nodes are stations, and every Work rides a route from search to screen. Refuses the stat-card dashboard and the poster wall as home.
OWN-WORLD: midnight enamel (#0A0F1E, #0E1527, #131C33), porcelain ink #EDF1F7, line inks Acquire #F0524F, Library #3D7BFF, Process #F4A62A, Deliver #22C08A, Notify #A99BFF; delayed is an amber ring, suspended a dashed grey line. Barlow for UI, Barlow Condensed for line bullets and dense labels.
STORY: the admin reads a status line and a map, sees the delay at forge and den suspended, and checks the departures.
FIRST VIEWPORT: 232 px labelled sidebar with counts; 52 px header with search and a disruptions pill; the status line; the network map with live trains beside Disruptions and Departures; a dense activity table below.
FORM: midnight transit diagram (catalogue challenger, fused). Signature move: the Network Map at 45 and 90 degrees with interchange stations and moving trains; line bullets wherever a Role appears; a Work's Route as an itinerary; on phones a vertical strip map. Raises: the chosen line burns and the rest dims (orienteering); departures update in place (split-flap); changed rows stay lit until noticed (gate board).
