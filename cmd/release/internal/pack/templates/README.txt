{{.Product}} {{.Version}}

Open {{.Trampoline}}.exe to start {{.Product}}. It opens your browser at the
setup page and puts its icon in the notification area.

{{.Product}} keeps its data in the data folder beside {{.Trampoline}}.exe, so
keep this folder somewhere you can write to. It does not start when you sign
in unless you turn that on from its icon.

{{.Executable}}.exe is the command-line program: run "{{.Executable}} stop" in this
folder to stop {{.Product}}.
